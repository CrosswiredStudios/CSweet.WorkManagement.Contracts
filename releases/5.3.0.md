Add durable `WorkDeliveryCorrection` handoffs, `CoordinateWorkDeliveryCorrectionRequest`, correction state on delivery-plan responses and `work.delivery.correction.coordinate.v1`. This is an additive wire contract release. Publish before SDK 5.11.0 and Producer 6.3.0. The platform requires the additive CorrectionsJson migration; no agent runtime payload or approved manifest is patched locally.
